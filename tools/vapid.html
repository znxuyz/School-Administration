手機提醒要用的一組金鑰。按下按鈕就會在你這台電腦上算出來 —— 不會送到任何地方,這個頁面也沒有連外。

① 公鑰(可以公開)

貼進 assets/config.js 的 VAPID_PUBLIC_KEY,也要填進 GitHub 的 Variables。

② 私鑰(機密,只貼進 GitHub Secrets)

不要貼進程式碼、不要傳給任何人(包括 AI 對話)。 拿到它就能冒充這個系統對全校老師發通知。

已複製
這兩串關掉頁面就沒了,也沒有存在任何地方。 先照下面的步驟貼好,再關視窗。真的弄丟就重產一組, 但重產會讓已經開啟提醒的人全部失效,要請他們再開一次。

接下來

  1. 公鑰 → 填進 GitHub repo 的 Settings → Secrets and variables → Actions → Variables 分頁 → New repository variable,名稱 VAPID_PUBLIC_KEY
  2. 公鑰 → 也要貼進 assets/config.js 的 VAPID_PUBLIC_KEY (這一步可以直接在 GitHub 網頁上編輯)
  3. 私鑰 → 同一個設定頁的 Secrets 分頁 → New repository secret, 名稱 VAPID_PRIVATE_KEY

完整步驟見 README 的〈手機提醒〉。
